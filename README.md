# Raquel Fernández · Portfolio

Portfolio personal de **Raquel Fernández Bermúdez**, Product Designer UX/UI con nueve años de experiencia en diseño editorial y formación en desarrollo front-end.

🔗 **Ver la web:** [raquelfernandezbermudez.github.io/raquel-portfolio](https://raquelfernandezbermudez.github.io/raquel-portfolio/)

---

## Sobre el proyecto

Una web de una sola página, diseñada y programada por mí, sin frameworks ni plantillas. El concepto visual parte de mi trayectoria, **de la página impresa a la pantalla**: tipografía editorial, marcas de corte y proyectos numerados como folios.

## Proyectos incluidos

| Proyecto | Tipo | Qué muestra |
|---|---|---|
| **Vera** | UX/UI · Investigación | App de alfabetización mediática contra la desinformación sobre feminismo. Análisis de soluciones existentes, wireframes y póster. |
| **App de transporte público** | UX Research · Arquitectura de información | Proceso completo: entrevistas, user personas, card sorting, árbol de contenidos, prototipo navegable y test de usabilidad. |
| **Social Objective** | Identidad visual · Infografía | Identidad para una plataforma de fotografía social: símbolo, logotipo, manual y aplicaciones. |
| **Infancias robadas** | Tipografía · Redes sociales | Serie de stories de Instagram sobre el matrimonio infantil. |
| **Diseño editorial y publicitario** | Editorial · Profesional | Libros técnicos de veterinaria y anuncios para Grupo Asís Biomedia. |

## Tecnologías

- **HTML5** semántico
- **CSS3**: Grid, Flexbox, variables CSS, diseño responsive y soporte de `prefers-reduced-motion`
- **JavaScript** sin librerías: carruseles, lightbox con teclado, filtros de proyectos, menú móvil y animaciones al hacer scroll
- Publicada con **GitHub Pages**

## Accesibilidad

- Navegación completa con teclado y estilos de foco visibles
- Textos alternativos descriptivos en todas las imágenes
- Atributos ARIA en el menú, los carruseles y el lightbox
- Animaciones desactivadas si el sistema tiene activado "reducir movimiento"

## Verlo en local

No necesita instalación. Clona el repositorio y abre `index.html` en el navegador:

```bash
git clone https://github.com/raquelfernandezbermudez/raquel-portfolio.git
cd raquel-portfolio
open index.html        # en Windows: start index.html
```
